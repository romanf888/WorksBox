1. Présentation de la Plateforme WorksBox

Origine, vision et fonctionnement global

WorksBox High School System est la plateforme numérique centralisée de partage de cours, sujets de travaux pratiques, ressources scolaires et logiciels éducatifs pour les filières de lycée (BTS SIO 1/2, Terminale STI2D, Bac Pro, etc.).

📚 Cours & Fiches PDF

Accès instantané aux cours triés par établissement, classe et matière avec lisez-moi intégré.

☁️ Drive Cloud 1 Go

Espace de stockage personnel sécurisé pour conserver vos TP, devoirs et fiches de révision.

💬 Espace Communautaire

Chat en direct par salons, suggestions de documents aux enseignants et editeur de notes WorksBox Note.

📚

2. Consultation, Filtres & Fiches de Cours

Comment rechercher et utiliser les cours efficacement

Filtrage dynamique par Établissement et Classe

Sur la page d'accueil de WorksBox, vous pouvez sélectionner votre établissement (ex: Lycée François Bazin, Lycée Monge) et votre classe (ex: BTS SIO 1, Terminale STI2D) pour n'afficher que les ressources qui vous concernent directement.

Fonctionnalités clés du lecteur de cours :

  • Aperçu PDF interactif : Visualisez les fichiers PDF directement dans le navigateur sans téléchargement obligatoire.
  • Mise en Favoris : Cliquez sur l'étoile ★ pour retrouver immédiatement le cours dans votre espace profil.
  • Suggestion de documents : Un bouton dédié permet d'envoyer un sujet ou cours aux administrateurs pour publication.
☁️

3. WorksBox Cloud & Cloud Partagé

Gestion des fichiers et quotas de stockage

Chaque compte utilisateur connecté via Google bénéficie d'un espace privé WorksBox Cloud de 1 Go. Les fichiers sont stockés de manière sécurisée et synchronisés sur vos différents ordinateurs.

👥 Espace Cloud Partagé de l'Établissement

Un espace collaboratif permet aux élèves de partager des exercices résolus, fiches de révision et ressources ouvertes contrôlées par les modérateurs.

🧮

4. Tutoriels Calculatrices CASIO & NumWorks

Guides pratiques pour les examens et la programmation Python

WorksBox intègre un module de guides étape par étape pour l'utilisation des calculatrices scientifiques et graphiques aux épreuves du Baccalauréat et du BTS.

Calculatrices CASIO Graph 35+ / 90+E

Activation du mode examen, saisie de matrices et résolutions d'équations polynomiales.

Calculatrices NumWorks

Scripts en langage Python, tracé de fonctions et suites numériques récurrentes.

5. Sécurité, Mode Maintenance & Mode Panne

Protection du système et mécanismes de rétablissement

🚧 Mode Maintenance (WorksBox Limited)

Désactive la suite logicielle et le Cloud pour maintenir l'accès exclusif aux cours pendant les périodes d'évaluation.

🚨 Mode Panne (Défense Interactive 503)

En cas d'incident serveur, les utilisateurs sont redirigés sur une page animée interactive avec rétablissement automatique en temps réel dès le déblocage admin.

🧩

📋 Guide d'installation de l'extension BETA sur Google Chrome :

    Le code source est prêt dans le dossier /extension de l'application.

  2. 2 chrome://extensions

    Saisissez chrome://extensions/ dans la barre d'adresse Chrome.

  3. 3 Mode développeur

    Activez l'interrupteur Mode développeur en haut à droite.

  4. 4 Charger non empaqueté

    Sélectionnez le dossier extension/ pour activer l'extension dans votre navigateur !

7. Paramètres du Compte & Personnalisation

Options d'accessibilité, thème et gestion des données

Depuis votre Espace Profil sur WorksBox, un onglet dédié Paramètres du compte vous permet de configurer vos préférences :

  • Police Dyslexique (OpenDyslexic) : Améliore la lisibilité pour les élèves présentant un trouble DYS.
  • Mode Contraste Élevé : Renforce les bordures et les couleurs pour une lisibilité maximale.
  • Gestion du cache local : Réinitialisez les données locales en un clic en cas de besoin.
💬

8. Foire Aux Questions (FAQ)

Questions fréquentes et assistance

Comment suggérer un nouveau cours ?

Sur la page d'accueil, cliquez sur le bouton Suggérer un document pour soumettre votre fichier ou lien aux administrateurs.

Que faire si mon stockage Cloud est plein ?

Chaque compte dispose de 1 Go d'espace. Vous pouvez supprimer d'anciens fichiers ou utiliser le Cloud Partagé de l'établissement.
